# 🎵 Music Database (PostgreSQL)

This project explores a music store database using PostgreSQL and pgAdmin 4.  
It includes SQL queries for business insights such as top customers, revenue by city, and genre analysis.

## 📂 Contents
- `schema.png` – ER diagram of the database
- `queries.sql` – SQL queries (Q1–Q7)
- `screenshots/` – Query results from pgAdmin

## 🧠 Key Insights
- Top customers by spending
- Cities generating highest revenue
- Rock music listener demographics
- Tracks longer than average duration

## 🛠 Tools Used
- PostgreSQL 18
- pgAdmin 4
- Git & GitHub
